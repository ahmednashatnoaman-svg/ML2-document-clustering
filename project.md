We will be working on an *Unsupervised Learning Document Clustering Project*, applying clustering techniques on two datasets:

•⁠  ⁠*People Wikipedia Dataset*: Biographical articles containing URIs, names, and extracted text
•⁠  ⁠*20 Newsgroups Dataset*: ~20,000 documents covering multiple topics

---

*Scope of Work*

•⁠  ⁠Data collection and preprocessing
•⁠  ⁠Feature extraction (TF-IDF as baseline, optional embeddings)
•⁠  ⁠Clustering:

  * K-Means
  * Hierarchical Clustering
  * Gaussian Mixture Models
•⁠  ⁠Evaluation:

  * Silhouette Score
  * Cluster interpretation (top terms, examples)
•⁠  ⁠Visualization:

  * PCA / t-SNE
  * Dendrograms

---

*Expected Deliverables*

•⁠  ⁠Structured and modular code
•⁠  ⁠Cleaned and preprocessed datasets
•⁠  ⁠Evaluation metrics and analysis
•⁠  ⁠Visualizations
•⁠  ⁠Final report
•⁠  ⁠⁠deployed app

---

*Code Requirements*

•⁠  ⁠Clear modular structure (preprocessing, features, clustering, evaluation, visualization)
•⁠  ⁠Well-commented and readable code
•⁠  ⁠Reproducible results (fixed seeds where applicable)
